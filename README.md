# Portfolio

A personal portfolio website that was designed to show not only my technical expertise, but also my personality. I love computers and programming and so I used a TUI (terminal UI) aesthetic with retro features / monospaced font to make it feel like using a separate computer. 

Built with Next.js and vanilla JS and CSS, no fancy tailwind, or typescript or anything.

---

## Inspiration

| Source                                                                                 | Idea Adopted                                                    |
